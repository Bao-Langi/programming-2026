# Построение бинарного дерева

Необходимо реализовать нерекурсивную функцию gen_bin_tree, которая строит бинарное дерево.

Параметры:

- root = 12
- height = 4
- левый потомок: root ** 3
- правый потомок: (root * 2) - 1

## Решение

Дерево хранится в виде словаря. Для построения используется цикл, чтобы функция являлась нерекурсивной.

```python
def gen_bin_tree(height: int = 4, root: int = 12) -> dict:
    """Создает бинарное дерево заданной высоты.

    Args:
        height: Высота дерева.
        root: Значение корня дерева.

    Returns:
        Построенное бинарное дерево в виде словаря.
    """
    tree = {
        "value": root,
        "left": None,
        "right": None
    }

    current_level = [tree]

    for level in range(1, height):
        next_level = []

        for node in current_level:
            value = node["value"]

            left_value = value ** 3
            right_value = (value * 2) - 1

            left_node = {
                "value": left_value,
                "left": None,
                "right": None
            }

            right_node = {
                "value": right_value,
                "left": None,
                "right": None
            }

            node["left"] = left_node
            node["right"] = right_node

            next_level.append(left_node)
            next_level.append(right_node)

        current_level = next_level

    return tree


tree = gen_bin_tree()
print(tree)
```
