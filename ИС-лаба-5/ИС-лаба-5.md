# Лабораторная работа №5
## Проектирование реляционной БД до НФБК

**Исходное отношение**:
HDD (Производитель, Web-сайт, Модель, Объём, Скорость вращения, Интерфейс, Серийный номер, Дата приобретения, Дата выхода из строя, Комментарий)

**Функциональные зависимости**:
- Серийный номер → Модель, Дата приобретения, Дата выхода из строя, Комментарий
- Модель → Производитель, Объём, Скорость вращения, Интерфейс
- Производитель → Web-сайт

**1НФ**:
Все значения уже атомарные.

**2НФ**:
Ключ — Серийный номер. Частичных зависимостей нет.

**3НФ**:
Транзитивные зависимости:
- Серийный номер → Модель → Производитель → Web-сайт
- Серийный номер → Модель → Объём, Скорость, Интерфейс

Декомпозиция:

| Отношение | Атрибуты | Ключ |
|---|---|---|
| Производитель | Производитель, Web-сайт | Производитель |
| Модель | Модель, Производитель, Объём, Скорость вращения, Интерфейс | Модель |
| Диск | Серийный номер, Модель, Дата приобретения, Дата выхода из строя, Комментарий | Серийный номер |
