# Лабораторная работа №3
## Тема: Основные операции реляционной алгебры

## Задача 1

**Определить имена и телефоны клиентов, которые в одном заказе указали не менее двух игр с разными названиями.**

R1 = П Номер заказа, Название игры (ПЗ)

R1' = R1

R2 = R1 ⋈ R1.Номер заказа = R1'.Номер заказа AND R1.Название игры ≠ R1'.Название игры R1'

R3 = П Номер заказа (R2)

R4 = R3 ⋈ R3.Номер заказа = З.Номер З

R5 = П Имя, Телефон (R4 ⋈ К)

**Ответ:** Михаил, 8-921-333-24-24.

## Задача 2

**Найти табельный номер сотрудника, оформившего заказ, который включает игру с минимальным возрастом игроков 12 лет.**

R1 = σ Мин возраст = 12 (И)

R2 = П Номер заказа (ПЗ ⋈ ПЗ.Название игры = R1.Название AND ПЗ.Производитель = R1.Производитель R1)

R3 = П Таб номер (R2 ⋈ R2.Номер заказа = З.Номер З)

**Ответ:** C01.

## Задача 3

**Найти фамилии и имена клиентов, купивших игры с минимальным количеством игроков 2, а максимальным — 6.**

R1 = σ Мин игроков = 2 AND Макс игроков = 6 (И)

R2 = П Номер заказа (ПЗ ⋈ ПЗ.Название игры = R1.Название AND ПЗ.Производитель = R1.Производитель R1)

R3 = П id клиента (R2 ⋈ R2.Номер заказа = З.Номер З)

R4 = П Фамилия, Имя (R3 ⋈ К)

**Ответ:** Швыркин Михаил.
