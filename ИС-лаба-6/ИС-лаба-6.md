- **Customer → Order**: 1:M (один заказчик — много заказов)

## Замечание по MySQL / Access

в Microsoft Access для ограничения числа строк используется `TOP n`, в MySQL — `LIMIT n`. Синтаксис `LIKE` также имеет отличия: в MySQL чувствительность к регистру зависит от используемой collation, в Access поведение `LIKE` определяется настройками базы данных.

## Задание 4.2: Простые запросы на SQL

### 0_Все авторы_повторения
```sql
SELECT Author FROM Book;
```
Выводит авторов всех книг, включая повторы.

### 1_Авторы без повторений
```sql
SELECT DISTINCT Author FROM Book;
```
Убирает повторяющихся авторов.

### 2_Авторы без повторений сортировка 1
```sql
SELECT DISTINCT Author FROM Book
ORDER BY Author;
```
Список авторов без повторов в алфавитном порядке.

### 3_Авторы без повторений сортировка 2
```sql
SELECT DISTINCT Author, BookYear FROM Book
ORDER BY Author ASC, BookYear DESC;
```
Пары «автор — год», сортировка по автору возрастанию, внутри автора — по году убыванию.

### 4_Книги сортировка
```sql
SELECT * FROM Book
ORDER BY BookYear ASC, Title ASC;
```
Все книги от старых к новым; при одинаковом годе — по названию.

### 5_Две последние книги
**MySQL:**
```sql
SELECT * FROM Book
ORDER BY BookYear DESC
LIMIT 2;
```
**Access:** `SELECT TOP 2 * FROM Book ORDER BY BookYear DESC;`

### 6_Половина списка
Первая половина списка, упорядоченного по возрастанию года (в таблице 6 книг → 3 записи).
**MySQL:**
```sql
SELECT * FROM Book
ORDER BY BookYear ASC
LIMIT 3;
```
**Access:** `SELECT TOP 50 PERCENT * FROM Book ORDER BY BookYear ASC;`

### 7_Запрос к связанным таблицам (INNER)
```sql
SELECT BookInLib.LibID, Book.Author, Book.Title
FROM Book
INNER JOIN BookInLib ON Book.BookID = BookInLib.BookID;
```
Только книги, имеющие экземпляры в библиотеке.

### 8_Запрос к связанным таблицам (LEFT)
```sql
SELECT BookInLib.LibID, Book.Author, Book.Title
FROM Book
LEFT JOIN BookInLib ON Book.BookID = BookInLib.BookID;
```
Добавляются книги без экземпляров (у них `LibID` = NULL).

### 9_книги с 1997 по 2001
```sql
SELECT Author, Title, Publisher, BookYear FROM Book
WHERE BookYear BETWEEN 1997 AND 2001;
```

### 10_книги с 1997 по 2001 IN
```sql
SELECT Author, Title, Publisher, BookYear FROM Book
WHERE BookYear BETWEEN 1997 AND 2001
  AND Publisher IN ('Азбука','Политехника');
```

### 11_книги с 1997 по 2001 OR
```sql
SELECT Author, Title, Publisher, BookYear FROM Book
WHERE BookYear BETWEEN 1997 AND 2001
  AND (Publisher = 'Азбука' OR Publisher = 'Политехника');
```
Эквивалентен запросу 10.

### 12_Авторы Like
Названия книг после 1999 г., автор начинается на «Г» **или** издательство заканчивается на «а», в обратном алфавитном порядке.
```sql
SELECT Title FROM Book
WHERE BookYear > 1999
  AND (Author LIKE 'Г%' OR Publisher LIKE '%а')
ORDER BY Title DESC;
```

### 13_Анализ запроса
```sql
SELECT * FROM Book
WHERE Author LIKE 'A%' OR BookYear > 2000 AND NOT Publisher LIKE 'И%' AND NOT Publisher LIKE 'П%';
```
**Что делает:** выбирает книги, у которых автор начинается на «A», **ИЛИ** (год > 2000 **И** издательство не начинается на «И» и не начинается на «П»). Приоритет: `NOT` → `AND` → `OR`.

В Access оригинал: `Author LIKE 'A*' OR BookYear > 2000 AND NOT Publisher LIKE '[И,П]*'` — маска `[И,П]*` означает «начинается с И или П».
