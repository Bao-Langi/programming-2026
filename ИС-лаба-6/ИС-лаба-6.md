## 2. Первичные ключи

- **Customer** — `CustomerNum`
- **Product** — `CatalogNum`
- **Order** — `OrderNum`
- **OrderItem** — составной ключ `(OrderNum, CatalogNum)`

## 3. Обязательные атрибуты (NOT NULL)

Все атрибуты во всех таблицах являются обязательными.

## 4. Связи между отношениями

- **Customer → Order**: 1:M (один заказчик — много заказов)
- **Order → OrderItem**: 1:M (один заказ — много позиций)
- **Product → OrderItem**: 1:M (один товар — много позиций в заказах)

## 5. Внешние ключи

- **Order.CustomerNum** → `Customer.CustomerNum`
- **OrderItem.OrderNum** → `Order.OrderNum`
- **OrderItem.CatalogNum** → `Product.CatalogNum`

## Замечание по MySQL / Access

в Microsoft Access для ограничения числа строк используется `TOP n`, в MySQL — `LIMIT n`. Синтаксис `LIKE` также имеет отличия: в MySQL чувствительность к регистру зависит от используемой collation, в Access поведение `LIKE` определяется настройками базы данных.
